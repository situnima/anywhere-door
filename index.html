    导入反馈

      效率操作

      快捷键与快速搜索

      快捷键

      • 聚焦搜索/
      • 命令搜索Cmd/Ctrl + K
      • 打开结果Enter
      • 新建站点N
      • 关闭或清空Esc

      搜索行为

      • 只匹配名称和网址，不搜索描述、标签和备注。
      • 没有高亮结果时，回车会默认打开首条可见站点。
      • 分类导航会随着搜索结果和滚动位置自动同步。

      关于

      本地存储与范围说明

      数据边界

      • 所有数据只保存在当前浏览器，无登录、无后端、无自动同步。
      • 清除浏览器数据或更换浏览器后，需要通过 JSON 导入恢复。
      • 上传图标和上传壁纸也保存在当前浏览器，并可随 JSON 一并迁移。

      当前版本范围

      • 支持分类导航、搜索过滤、站点管理、拖拽排序和本地持久化。
      • 支持主题、壁纸、布局密度、卡片样式和链接打开方式设置。
      • V1 仅以现代桌面浏览器为目标，不包含账号体系与跨设备同步。
